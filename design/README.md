# Design

`starling-almanac/` is murmur's design system: the brand book (`README.md`), the tokens
(`tokens.json`, Lamplight and Dusk), the components (`components/murmur.css`, the classes;
`components/flock.js`, the live murmuration; one folder per component with its guideline and a
live preview), and the logos (`logos/`, drawn by `logos/draw_mark.py`).

The browsable version is the Design System artifact the owner reviews; this folder is its source
in the repository, so the dashboard and the landing page build from the same files.
