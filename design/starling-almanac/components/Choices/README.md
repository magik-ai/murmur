# Choices

Checkbox, radio and switch.

- Checkbox (`mm-check`): several independent yes-or-no choices, applied when the form is sent. A rounded square, `accent` when checked, a dash when some of a group are checked.
- Radio (`mm-radio`): one of a few, all visible, applied when the form is sent. For more than five options use a select; for options with detail use `ChoiceCard`.
- Switch (`mm-switch`, `role="switch"`): something on or off right now, applied at once, no Save button.

The label is the whole click target and says what is on when the control is on.
