# Tile

One figure with its label and a note: the machine at a glance.

The owner's rule: the label sits on the top edge, the value on the top edge, the note on the bottom edge, so a row of tiles never jumps whatever their notes say. The value is set in `figure` (IBM Plex Mono, tabular); the note is one line, cut with an ellipsis, its full text in the `title`.

Use tiles only for the few figures a person scans first (load, memory, disk, the sweep). A sentence is not a tile.
