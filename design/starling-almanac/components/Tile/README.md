# Tile

One figure with its label and a note: the machine at a glance.

`mm-tile` puts a label (`mm-tile__label`) and a value (`mm-tile__value`) at the top and a note (`mm-tile__note`) at the bottom, so a row of tiles (`mm-tiles`) lines up whatever the notes say. The value is set in `figure` (IBM Plex Mono, tabular). The note is one line, cut with an ellipsis, with its full text in the `title`.

Use tiles only for the few figures a person looks at first, such as load, memory and disk. A sentence is not a tile.
