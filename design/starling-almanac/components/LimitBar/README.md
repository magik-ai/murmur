# LimitBar

A subscription window: its name, a rail, and the percent in mono, on one line.

The fill is `accent` below 70 percent, `warning` from 70 (`data-tone="wait"`) and `danger` at 95 and over (`data-tone="fail"`); the percent takes the same ink. Show every window the account has, the model-scoped ones (Fable) included: hiding the spent one is how an account reads fine while it is not.

The consumer provides the name, the percent, and the tone.
