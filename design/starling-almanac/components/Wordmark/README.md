# Wordmark

The mark and the name.

The mark is the lamp-lit bird and the seven it watches. Use `murmur-mark.svg` on light grounds and `murmur-mark-dusk.svg` on dark ones, at every size: the same drawing holds from 16 px up. The name is set in Fraunces at its softest, with its wonky letterforms, lowercase, always "murmur": the wordmark is the one place the serif appears inside the app, because it is the logo, not a heading. Keep clear space of half the mark's height around the lockup; never recolour the birds, never add a tagline to the lockup.
