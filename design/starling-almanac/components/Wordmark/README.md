# Wordmark

The mark and the name.

The mark is the lamp-lit bird and the seven it watches. Use [`murmur-mark.svg`](../../logos/murmur-mark.svg) on light backgrounds and [`murmur-mark-dusk.svg`](../../logos/murmur-mark-dusk.svg) on dark ones. The same drawing works at every size from 16 px up.

The name is always "murmur", in lowercase, set in Fraunces at its softest and with its wonky letterforms (`WONK` 1). The wordmark (`mm-wordmark`) is the one place the serif appears inside the app, because it is the logo, not a heading.

Keep clear space of half the mark's height around the lockup. Never recolour the birds, and never add a tagline to the lockup.
