# EmptyState

An empty place invites the person to act.

`mm-empty` holds a title (`mm-empty__title`, Instrument Sans) that states the fact ("No machine but this one"), one sentence (`mm-empty__body`) that says what to do, and the button that does it. Add `mm-stipple` for the engraving grain. A dashed `line-strong` border with `radius-md` marks the place where things will appear.
