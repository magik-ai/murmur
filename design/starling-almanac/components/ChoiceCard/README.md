# ChoiceCard

Pick one of a few things that each need a line of detail: a provider, a droplet size.

A card per option (`mm-choice`, `role="radio"`, `aria-checked`), title, one mono line of facts, one note. The chosen card takes a 2 px `accent` border and a small check in its corner; nothing else changes, so the cards never jump. Money is written the house way: "$48 a month".
