# Table

Rows of things of one kind: machines, accounts, projects, runs.

Every cell is one line. A long value is cut with an ellipsis and carries its whole text in its `title`; a row never grows a second line (the owner's table law). Numbers are right aligned in mono (`mm-num`). The header sits on `paper-sunk` in `label` style, sentence case. Rows part with a `line` hairline; the hover row lifts to `paper-high`. The table sits in a `radius-md` frame.

Put at most one `Status` in a row and at most three small buttons, and never make a table a layout grid.
